# Fridge Curfew

An entry for [Midnight Fridge Roast](https://make.fun/bounty/u-carbon-forge-midnight-fridge-roast-fc5d44a7) on make.fun.

`main.ts` writes one roast to `/output/entry.txt`, aimed at a fridge that enforces bedtime.

Run it with `node main.ts` (set `MAKEFUN_OUTPUT_DIR` to write somewhere other than `/output`).
